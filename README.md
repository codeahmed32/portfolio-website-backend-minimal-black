# Minimal Black - Portfolio Backend API

The RESTful backend service powering the Minimal Black Portfolio Website. Built with Node.js, Express, and MongoDB to handle dynamic content, contact form submissions, and data management.

## 🚀 Features

* **RESTful API Architecture:** Structured endpoints for managing portfolio data, messages, and project info.
* **Database Integration:** MongoDB with Mongoose schemas for flexible document management.
* **Environment Configuration:** Secure environment variable management for database URIs and sensitive keys.
* **CORS & Security:** Configured CORS headers to secure communication with the frontend client.

## 🛠️ Tech Stack

* **Runtime:** Node.js
* **Framework:** Express.js
* **Database:** MongoDB (Mongoose ODM)
* **Environment Management:** Dotenv
* **Deployment:** Railway / Render
